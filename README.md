# Terminal Intro — Sandeep S Rajesh

An interactive terminal-style intro page. On load it auto-types a boot sequence
(`$ whoami`, `$ cat skills.txt`, `$ echo "Building. Automating. Securing."`)
while a second line cycles through 6 roles. Type commands in the input or tap
the clickable command chips — `help`, `whoami`, `about`, `skills`, `experience`,
`labs`, `projects`, `learning`, `contact`, `clear` — with command history
(↑/↓), Tab autocomplete, Ctrl+L clear, and a `sudo hire sandeep` easter egg.

## Live demo

https://skullace-25.github.io/terminal-intro

## Run locally

Open `index.html` in any browser — no build step, no server needed.
